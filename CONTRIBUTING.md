Contributing to QUICKPASS
Thank you for your interest in contributing to QUICKPASS, an academic project focused on developing a digital pass and recharge system for public transportation.
All contributions that help improve the project are welcome, from bug fixes to new feature suggestions.
How to Contribute
1. Identify What You Want to Improve
Before making changes, check the existing Issues in the repository to see whether the problem or suggestion has already been reported.
2. Suggest Improvements or Report Bugs
Use GitHub Issues to report problems, suggest new features, or discuss potential improvements to the system.
When reporting a bug, describe what happened, the steps taken to reproduce it, and the expected result.
3. Make Your Changes
If you want to contribute code:
Fork the repository or create a branch for your changes, depending on the available permissions.
Make the necessary modifications.
Test your changes to ensure they work correctly.
Write clear commit messages describing the changes made.
4. Submit Your Contribution
Once your changes are ready, submit them through a Pull Request, explaining what was changed and why the contribution is useful to the project.
Contributions may be reviewed before being merged into the main repository.
Best Practices
Keep the code organized and readable.
Avoid changes unrelated to the proposed contribution.
Follow the project's Code of Conduct.
Never commit passwords, tokens, credentials, or other confidential information.
Whenever possible, test your changes before submitting them.
Document important changes to the system's behavior.
Project Scope
QUICKPASS is an academic project involving a mobile application, backend, database, and a physical prototype using an ESP32 and an RFID reader.
Contributions related to the security, reliability, usability, and maintenance of these components are welcome.
Questions
If you have any questions, use the repository's Issues section or contact the project maintainers through the contact channels provided.
Thank you to everyone who contributes to the development and improvement of QUICKPASS!
